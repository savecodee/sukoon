# سكون

مؤقت بومودورو عربي هادئ. جلسات تركيز واستراحة، مهام الدورة، درجة، وشجرة تكبر مع وقت التركيز.

## التشغيل

```bash
npm install
npm run dev
```

يفتح على `http://localhost:8080`.

## النشر

المستودع جاهز لـ [Vercel](https://vercel.com): استورد المشروع واترك أمر البناء `npm run build`. التقدم يُحفظ في المتصفح، ولا يحتاج قاعدة بيانات.
